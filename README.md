## 💭 About This Project
<p>A simple and aesthetic Pomodoro timer designed to help you stay focused and productive. Customize your study sessions, take scheduled breaks, and enjoy your favorite music with the built-in Spotify player.</p>

## 🎀 Functions 
- ೃ⁀➷ **Three timer modes** — pomodoro (25 min), short break (5 min), long break (15 min), each independently editable.
- ೃ⁀➷ **Start / pause / reset** — a single button toggles the countdown, and reset snaps the active mode back to its full time.
- ೃ⁀➷ **Settings widget** — settings panel where you can change how long each mode runs, then save or reset back to defaults.
- ೃ⁀➷ **Music widget** — an embedded Spotify player defaulting to a chosen playlist. Tapping the Spotify button on its corner lets you swap in a different playlist, album, or track link at any time.
